Fase 3: Preparación de los Datos

Procesamiento matemático y estructuración de tensores requeridos antes de alimentar la red neuronal.

Flujo de Transformación
1
Reshape Estructural Se expanden las dimensiones de (28,28) a (28,28,1) para agregar explícitamente el canal de color (escala de grises) exigido por Keras.
2
Escalado Min-Max (0 a 1) Conversión a float32 y división por 255. Estabiliza el cálculo de los gradientes acelerando la convergencia del entrenamiento.
3
One-Hot Encoding Transformación de etiquetas numéricas (ej. '5') a vectores binarios de 10 posiciones para acoplarse a la entropía cruzada.
Código del Pipeline de Datos (.py)
# 1. Ajuste de dimensiones de entrada para capas convolucionales x_train = x_train.reshape(60000, 28, 28, 1) x_test = x_test.reshape(10000, 28, 28, 1) # 2. Normalización lineal: mapeo de enteros [0, 255] a reales [0.0, 1.0] x_train = x_train.astype('float32') / 255 x_test = x_test.astype('float32') / 255 # 3. Codificación categórica para la capa de salida Softmax y_train = to_categorical(y_train, 10) y_test = to_categorical(y_test, 10)

Fase 4: Modelado

Topología jerárquica y secuencial de la Red Neuronal Convolucional (CNN).

Grafo Declarativo Keras
model = Sequential() # Bloque 1: Extracción Inicial model.add(Conv2D(32, (3,3), activation='relu', input_shape=(28,28,1))) model.add(MaxPooling2D(pool_size=(2,2))) # Bloque 2: Características Profundas model.add(Conv2D(64, (3,3), activation='relu')) model.add(MaxPooling2D(pool_size=(2,2))) # Bloque 3: Clasificación Densa model.add(Flatten()) model.add(Dense(128, activation='relu')) model.add(Dropout(0.5)) model.add(Dense(10, activation='softmax'))
Pipeline de Capas Secuenciales
Conv2D
32 Filtros (3x3) + Activación ReLU Input: (28, 28, 1) → Output: (26, 26, 32)
MaxPool
MaxPooling (2x2) Reduce resolución a la mitad → Output: (13, 13, 32)
Conv2D
64 Filtros (3x3) + Activación ReLU Abstrae rasgos complejos → Output: (11, 11, 64)
MaxPool
MaxPooling (2x2) Output final de features → Output: (5, 5, 64)
Flatten
Aplanamiento de Tensores Conversión a vector lineal → Output: (1600 Neuronas)
Dense
Capa Intermedia Interconectada 128 Neuronas con activación ReLU
Dropout
Regularización Estocástica (0.5) Apaga el 50% de nodos al azar para mitigar Overfitting
Dense Out
Capa de Salida (Softmax) 10 Neuronas probabilísticas (Dígitos del 0 al 9)

Fase 6: Despliegue y Monitoreo

Estrategia de exportación persistente e ingeniería de calidad en el ciclo de producción.

Serialización en Script (.py)

El script del grupo asegura el guardado del artefacto en formatos robustos:

# Persistencia en Google Drive model.save("../modelo_mnist.keras") # Exportación nativa para la Web (TensorFlow.js) model.export("../modelo_web")
Arquitectura en Producción e Ingeniería de Calidad
  • Backend (Servidor de Inferencia): Se consume la carpeta exportada modelo_web para disponibilizar predicciones mediante microservicios eficientes.
  • Tratamiento de Datos de Entrada: Cualquier imagen externa capturada por cámara en producción debe pasar por filtros de umbralización y redimensión estricta a matrices de 28x28 píxeles antes de la predicción.
  • Mitigación de Data Drift: Monitoreo constante de la confianza probabilística de la capa Softmax. Caídas repetitivas bajo el 85% disparan alertas de re-entrenamiento con nuevos estilos de escritura.
